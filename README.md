# 财经博主定向研究方案

**v0.1.5 · 受限使用公开方法包 · 2026-10-25**

本包只提供研究过程的文字、模板与示例，不是财经服务、交易工具或投资建议。允许个人非商业学习与自用；未经明确同意，不授权商业/营利使用及修改后再发布。详见[使用条款](LICENSE.md)与[许可边界](LICENSING.md)。本条款未额外授予原版站外再分发权限，推荐分享原仓库链接；GitHub 平台许可与法定权利保留。

给需要持续研究某位财经博主公开表达的人：把“他说过什么、什么条件下说的、哪些事实能核验、哪里还不知道”做成可追溯记录，而不是只收集金句。

**第一次只研究一个问题，完成一份批次研究单。** 里面包括来源与短摘、观点与事实对照、明确结论或停止原因、核对与下次触发条件。它不是一份自动生成的投资报告。

## 从这里开始

**[首次使用：只走这一条短路径](START_HERE.md)** → 复制 [一批研究单](finance/FIRST_BATCH_TEMPLATE.md) → 对照 [已填好的纯合成财经案例](finance/EXAMPLE_BATCH.md)。

不用安装软件、接 API、购买数据或阅读所有文件；普通文本编辑器即可。没有真实材料时，先用包内合成材料离线演练。第一批不要求填齐 8 张高级模板，也不要求提出“投资方法”。

想看真实来源如何收口，可另读 [单文档真实小批次摘要](finance/REAL_BATCH_EXAMPLE.md)：使用 v0.1.3 的 AI 辅助演练，保留协助、更正与失败；不必先读它，也不能把它当真人使用验证。

## 适合与不适合

| 适合用来做 | 不能据此得到 |
| --- | --- |
| 核对某个观点的原意、条件、前后变化及缺口 | 本人授权、真实内心或没有公开表达的当前立场 |
| 把作者说法与公告、财报等独立事实分开 | 把标题、转写或模型回答当已核实事实 |
| 有证据时提出候选方法，再另行试用和评估 | 预测胜率、买卖信号、收益保证或“已验证有效” |
| 留下可复核、可更正的研究过程 | 已接通的爬虫、行情终端、训练模型或自动化平台 |

本包默认不代表本人授权或背书；输出属于研究者归纳。不训练模型、不复制人格、不模仿本人发言。遇到未知就记录未知；材料不足也能完成一批，但不能声称已还原观点。
