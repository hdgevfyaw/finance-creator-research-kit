# 工具配方（不含下载器或已接通服务承诺）

**选配参考，不是首次上手步骤。** 第一批可用编辑器与人工阅读完成；[合成练习](EXAMPLE_BATCH.md) 不联网也能走通。

以下是可替换工具类别和产物约束，不表示这些工具已安装、已授权或在所有平台可用。先读来源条款；遇登录、付费、DRM、拒绝访问或验证码时停止自动采集，记录阻塞并使用合法人工入口。

| 工作 | 工具类别/可选例 | 输入→输出与验收 |
|---|---|---|
| 有界检索 | 官方站内搜索、网页浏览/搜索工具 | 作者名＋渠道＋时间窗→候选URL清单；先核身份，再去原始发布时间与正文，不把搜索摘要当证据 |
| 作者feed增量 | HTML解析器（如Python标准库）、集合差集 | 本次可见条目→来源ID/规范URL/原始时间；与前次ID比较，记录新增/消失；页面无新增只代表该次可见feed无新增 |
| 原片定位 | 原始发布页播放器、平台许可的导出或作者提供文件 | URL/来源ID→片长、说话人、时间段、取得状态；只在授权范围取媒体，不包装跨平台批量抓取器 |
| 转写与核听 | 本地或经批准的ASR、播放器逐段核听 | 已有合法媒体→分段文本＋起止秒＋说话人＋不确定处；金额、否定词、条件词、资产名需人工核对 |
| 画内字幕与图表 | OCR（可选Tesseract/PaddleOCR）、抽帧与人工复核 | 有权使用的关键帧→文字＋帧时刻＋区域；OCR与ASR有冲突时回看片段，不能擅自择一 |
| PDF财报 | PDF文本提取（如pdftotext/pypdf）＋页渲染 | 官方PDF→页码/表名/单位/字段；数值表必须核版面，跨页表、括号负数及千/百万元尤其易错 |
| 去重与版本 | SHA-256、规范URL、来源ID、文本近似检索 | 记录字节哈希与内容哈希；相同转载不算独立证据；同URL内容变化建新版本；近似重复不自动删除 |
| 行情核验 | SOURCES中实际地址或人工官方入口 | 响应→证券代码/交易日/收盘/口径；检查日期范围、空返回、顺序、缺日和币种，记录解析契约版本 |
| 公司回报核验 | 交易所公告检索、公司IR | 事件ID→阶段链；同一事项按公告衔接，不用媒体“拟分红”替代支付完成证据 |
| 证据审查 | 人工审校＋可选模型结构化提取 | 来源卡→观点卡；要求每一结论有来源定位，缺证据返回未知；模型不负责证明事实真假 |

## 限制、降级与重试

- 网络取得、内容可解析、字段核对、法律许可是四个独立状态。HTTP 200也可能是验证页或空壳。
- 对暂时性错误只做小规模有界重试，记开始/结束时间、错误类别和结果；持续拒绝就人工入口，不换身份绕过。
- API/页面改版触发契约失败：保留空值和错误，不让旧缓存假装新数据。旧数据可引用，但显式带原日期。
- 对原片先查是否已有同来源ID/字节哈希；没有新内容不重复下载。完整原文与媒体留在有权限的私有工作区，公开包仅带许可范围内的短摘与定位。
- 从“不含作者信息的市场基线”与“加入作者观点的研究版本”分别产出，可以检查归因；不得把后来事实倒灌进更早的版本。本包没有实验题或答案。

## 发布前检查

检查来源身份与URL、时间及时区、数值单位、结论与证据一一对应、冲突/反例、未知状态。扫描凭证和私有标识，检查包内实际文件清单；勿直接压缩整个研究目录。

下面仅为使用者在**有权处理、已经取得的本地文件**上自行运行的示例，本版未执行这些媒体命令：

```sh
# 只针对确认公开且许可允许保存的明确文档URL；不是平台批量下载器
curl --fail --location "$PUBLIC_DOC_URL" --output document.pdf
# 原片与内容元信息；请自行检查实际文件名与时间范围
ffprobe -v error -show_entries format=duration -of json authorized-input.mp4
ffmpeg -ss 00:00:30 -i authorized-input.mp4 -frames:v 1 frame.png
ffmpeg -i authorized-input.mp4 -vn -ac 1 -ar 16000 audio.wav
# 表格提取后还要核对渲染页，不能单靠文本顺序
pdftotext -layout document.pdf document.txt
pdftoppm -f 1 -singlefile -png document.pdf page-1
sha256sum document.pdf
```

ASR/OCR输出只作候选证据；未安装的引擎不提供虚构调用结果。若改用外部转写/模型服务，先确认媒体上传许可、供应商数据政策、费用及真实官方接口，再把凭证放入外部密钥存储。
