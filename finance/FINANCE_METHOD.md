# 财经专用方法：把可核验的约束写进流程

## 1. 先冻结时间边界，再读内容

分别记录 `published_at`（页面声称发布时间）、`first_verified_public_at`（最早能证实的公开时间）、`fetched_at`（本次取得时间）、`event_at`、财报报告期和行情交易日。未知时间不猜；页面时区未知就保留原字符串。录制时间、转载时间不能自动当首次公开时间。

- 所有结论有 `as_of` 和允许使用的证据截止时刻；新证据只能生成新版本，不能回填旧时点答案。
- 休市日检查不产生“今日涨跌”；A/H交易日历、时区和收盘时间分开，20/60个交易日不等于同一自然日起点。
- 历史成分权重不是当前权重；指数改样前后保留篮子桥接表，不能把换入盈利公司造成的变化当原公司改善。

## 2. 作者证据、独立事实与研究推导分开

这里是信息类别，不替代通用的 L1 原作者 / L2 研究归纳 / L3 应用归属。独立事实是核验和应用的补充材料，不自动变成人物本人观点；研究归纳与新问题推演仍分别标为 L2 和 L3。

| 信息类别 | 可以写什么 | 不能跳跃到什么 |
|---|---|---|
| 作者证据 | 经核实身份的原话/短摘、时间戳、对象、期限、条件、保留词 | 标题或平台AI摘要不当完整原话；字幕不是市场事实认证 |
| 独立事实 | 官方行情、政策原文、财报与实施公告的可复算字段 | 作者复述、媒体转引不自动构成第二个独立来源 |
| 研究推导 | 明示“研究者归纳”，给适用范围、理由与推翻条件 | 不冒充作者量化公式，不推导不存在的买卖阈值 |

把“某类风险缓和”扩大成“所有风险解除”，或删除“可能/部分/有望”等条件，都是必须拦截的归纳错误。实际作者案例只能说明该人物在该语境下如何表达，不能预置成所有人物规则。

## 3. 公司回报必须追踪执行阶段

**分红：**提议/预案 → 所需批准 → 实施安排 → 股权登记/除权除息/计划支付日 → 支付完成证据。不同市场程序不同，缺失阶段保持未知；公告写了未来支付日不等于已经支付。

**回购：**授权/计划 → 交易进展 → 完成 → 用途（注销/员工激励等）→ 注销完成。用途变更批准不等于注销完成；金额上限不等于实际回购额。

每次升级保存公告日期、适用股类、币种、税前税后、每股/总额、状态和证据定位。回报执行改善不单独证明指数将上涨。

## 4. 估值不能只比较一个“倍数”

最小口径键：`估值日 + 指数/证券 + 成分版本 + 币种 + PE/PB/股息率 + TTM/静态/预测 + 加权方法 + 亏损处理 + 分母来源`。

任一关键项缺失就标“不可直接比较”，不补编。官方月末加权PE、另一天TTM PE、分析师预测PE不机械排序。分红收益率区分历史/预期、常规/特别分红和价格时点。首页展示可读不代表已核验计算方法。

## 5. 银行与实业企业分两条财务核验链

- **实业/平台等非银行企业：**归母与扣非利润分开，核投资收益等非经常项目；经营收现、营运资本、应收、存货与资本开支分开。若使用“经营现金流－资本开支”，明确资本开支包含项、资本化研发、租赁和币种；它是口径化代理指标，不自动等同可分配现金。
- **银行：**净利息收入与净息差分开；收入增长可能来自规模或资金成本变化。并列看信用减值/信用成本、不良余额与比率、关注/逾期、拨备、核心一级资本及风险加权资产；不能套工业企业现金流减资本开支判断。
- **含财务子公司的集团：**合并经营现金流可能受存款/拆借等影响，不直接归因于产品回款。需看分部、附注和变动解释。
- 同比/环比、半年/全年、金额/增速、人民币/港元/美元不混用；先固定样本与选择依据，再查财报，减少按结论挑公司。

## 6. 用反例卡而非“正确率”装饰方法

只有在研究问题需要且证据支持时才提出候选规则，不强制把每个观点规则化。每条候选规则至少写：支持证据、反证、未覆盖范围、改变判断需要的下一原件；纯观点整理可在还原与核查后收口。

| 待检验推断 | 最小反例/反证检查 |
|---|---|
| 利润增长就是主业变好 | 扣非是否同步；投资收益与税项是否主导 |
| 经营现金流下降就是恶化 | 营运资本、采购时点、存款变动是否解释；不要与投资现金流重复归因 |
| 不良率下降就是风险全面下降 | 不良余额、逾期、关注和减值是否反向变化 |
| 一家权重改善代表全指数改善 | 覆盖权重、行业、其余成分与样本偏差是否清楚 |
| 政策发布代表资金已流入 | 区分征求意见/正式发布/生效/申请/批准/执行/实际规模 |
| 指数扩容代表必有净买入 | 成分调整、权重再平衡与资金净流入并非同一事实 |

停止条件：本窗口指定入口检查完，证据齐/缺、冲突及下一触发条件已记录；不为凑“完整”无限搜索。方法有效性需独立、时间隔离的评估；本包不声称预测增益。
