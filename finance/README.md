# 财经参考：按问题查，不必全部阅读

[首页](../README.md) · [首次使用](../START_HERE.md) · [一批研究单](FIRST_BATCH_TEMPLATE.md) · [合成案例](EXAMPLE_BATCH.md) · [真实小批次摘要](REAL_BATCH_EXAMPLE.md)

这是《财经博主定向研究方案》的选配参考层。先完成一个可追溯批次；材料确实需要行情、财报、政策或媒体处理时，再查下表。不是授权分身、投资建议、预测报告或已接通系统。

| 你现在要核什么 | 先看什么 | 找不到时如何收口 |
| --- | --- | --- |
| 博主实际说过什么、是否有条件或改口 | 原始发布渠道/原片；[工具配方](TOOL_RECIPES.md) 的定位与核听 | 只有摘要/标题则记线索，身份或上下文待核；不替作者定论 |
| 分红/回购是否实施，财报数字是否对得上 | [财经方法](FINANCE_METHOD.md) 第 3、5 节；来源清单 CNINFO、SSE-HOME、SZSE-HOME、HKEXNEWS 或公司 IR | 在对应公司/交易所官方检索入口人工找同一事项原件；仍无原件就记事实未核，不能由计划跳到完成 |
| 政策是否发布、生效或执行 | 财经方法第 6 节；CSRC、PBOC；按政策发布机关找原文 | 记录阶段、发布时间和缺失执行证据，不以新闻标题代原文 |
| 指数/估值是否可比 | 财经方法第 1、4 节；相应指数单张和编制方入口 | 历史接口不可达则用官方可读资料核有限字段；日期/口径不齐就写不可比较，不补数 |
| 有合法媒体但手工处理太慢 | [工具配方](TOOL_RECIPES.md) | 工具未装可人工核听/摘录；转写不清则保留疑点 |
| 已决定自行开发采集/存储 | [自定义采集契约](COLLECTION_CONTRACT.md) | 仅设计参考，不包含已实现适配器；第一次无需使用 |

[20 条来源清单 SOURCES.csv](SOURCES.csv) 用普通表格或文本编辑器打开即可，按 `source_id` 查上表，保留检查日期与失败状态。示例作者和公司地址只是入口样例，不是必选研究对象，也不承诺覆盖全部作者/证券。站点打不开时不绕过登录、付费或访问限制；更换来源必须重新核身份与口径，不能把第三方转载冒充同一原件。
